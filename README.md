# Daylight — React demo

A responsive task dashboard built with React and Vite. Includes task creation, completion toggles, search, project/status filters, live statistics, and localStorage persistence. The illustration uses CSS; no image assets are required. Google Fonts are optional and fall back to sans-serif.

## Run

Install Node.js 22 LTS or newer, then run in this directory:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```sh
npm run build
npm run preview
```

Demo tasks are saved in this browser only. Clear the `daylight-tasks` localStorage key to restore the sample data. No backend or account is needed.
